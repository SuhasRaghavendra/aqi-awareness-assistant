| D-009 | 2026-10-15 | Drop NH3, NOx, NO columns from cleaned panel (>70% missing) | Impute with zeros; retain as high-missing indicators | All three exceed the `params.yaml:clean.drop_cols_over_missing=0.7` threshold; retaining them would introduce mostly-imputed noise. | D-012 | 2026-10-15 | Include lags [1, 2, 3, 7] for AQI and PM2.5 based on ACF/PACF analysis | Lags [1, 3, 7] or longer lags | ACF/PACF (Fig 12) confirms significant autocorrelation specifically at lags 1, 2, 3, and 7 days. | D-013 | 2026-10-15 | ~~Weather merge restricts modelling panel to stations with matched weather files (Delhi)~~ **[UPDATED]** Use Open-Meteo ERA5 reanalysis weather for all 9 cities via coordinate-based API | IMD gridded data (requires registration); Delhi-only weather file; discard weather features | Open-Meteo ERA5 provides free, no-API-key, coordinate-based daily aggregates from 1940-present at ~0.25° resolution for all 9 cities simultaneously; eliminates the previous Delhi-only limitation | [Step 007](logbook/007-feature-engineering-and-split.md) |
| D-014 | 2026-10-15 | Dual evaluation strategy for Task B (Direct Multi-class Classifiers and Regress-Then-Bucket) | Only train direct classification models | Regress-Then-Bucket leverages continuous AQI predictions and achieves 97.97% within-one-category accuracy, while direct Random Forest Classifier achieves 0.6077 Macro-F1. | [Step 008](logbook/008-baseline-models-evaluation-and-mlflow-tracking.md) |
| D-015 | 2026-10-15 | Prioritize `import lightgbm` before pandas/pyarrow on Windows environments | Disable LightGBM; reinstall system C++ runtimes | Resolves an OpenMP C-runtime access violation caused by PyArrow's threading DLL colliding with LightGBM's C-API on Windows. | [Step 008](logbook/008-baseline-models-evaluation-and-mlflow-tracking.md) |
| D-016 | 2026-10-15 | Use project-local `.venv` directory for Python virtual environment | Windows Store Python global site-packages | Avoids Windows 260-character `MAX_PATH` file path exhaustion during package extraction (e.g. MLflow DB migration scripts). | [Step 008](logbook/008-baseline-models-evaluation-and-mlflow-tracking.md) |
| D-017 | 2026-10-15 | Retain full multimodal feature space (Lags + Weather + Spatial + Calendar) based on ablation evidence | Lag-only model; discard weather due to API latency | Dropping lags degrades RMSE by +10.50% (worse than persistence), and dropping weather degrades RMSE by +3.30%. | D-018 | 2026-11-10 | Restore D-004 documented chronological split: train≤2023-12-31, val 2024, test 2025+ | Keep previous params.yaml values (train_end 2022-12-31 / val_end 2025-12-31) | Previous params.yaml had train_end=2022-12-31 / val_end=2025-12-31 giving a test set of 83 rows from Hyderabad only. | D-019 | 2026-11-10 | Add day-t `aqi` as explicit feature and fix reindex bug in build_features.py | Leave aqi as implicit (derivable from lag+diff); keep buggy reindex | Root cause: `add_aqi_history_features()` called `.reindex(grp_idx)` on a DatetimeIndex-indexed Series using integer labels, returning all-NaN, filled to 0 by train medians. Adding `aqi` as explicit feature lifts val skill from ~0 to +0.11 for LGBM. | [Step 011](logbook/011-phase-0-baseline-fixes.md) |
| D-020 | 2026-11-10 | Single scaler: train.py and evaluate.py load `data/processed/scaler.joblib` fitted in build_features.py | Refit scaler separately in train.py and evaluate.py | Refitting in multiple stages produced three scalers with different statistics due to different data subsets, causing feature distribution mismatch between train and evaluate. | D-021 | 2026-11-10 | Add persistence-anchored residual Ridge and LightGBM candidates (target = target_aqi - aqi_t, prediction = aqi_t + model output) | Direct-level regression only | Every direct learned model initially lost to persistence. Modelling the day-over-day change gives the learner a persistence anchor while retaining the root-cause features. | D-022 | 2026-11-10 | Treat Pune as a known data-thin city in per-city reporting and gates | Drop Pune; compare Pune to the national mean without caveats | Pune has only 900 train rows (history starts in 2021) versus 1,820-1,826 for the other eight cities, so its per-city metrics have wider uncertainty. | D-023 | 2026-11-10 | Accept the documented G3 Kolkata red gate for the Phase 2 champion bundle | Retrain, change the 1.05 threshold, or block packaging until every city passes | G3 is the only failing gate: Kolkata test MAE is 15.04 vs persistence 13.77 (ratio 1.0922 > 1.05).
